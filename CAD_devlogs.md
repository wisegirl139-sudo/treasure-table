# Devlog 1 — Dowel Stand ([1.1](https://lapse.hackclub.com/timelapse/1ThQTO9-Yl7S), [1.2](https://lapse.hackclub.com/timelapse/18N\_vKCRP\_jl)) - Oliver



I started by creating the basic shape of the stand in Fusion 360, using circular features to position the dowel holes. I then built the main body, added the remaining holes and rounded the edges.



I made the design parametric by adding user parameters for the shelf height, depth, dowel diameter and number of dowels. I also created a formula to automatically calculate the hole spacing, allowing the design to be resized or changed without manually repositioning each hole.



# Devlog 2 — Parametric Shelf Top ([2.1](https://lapse.hackclub.com/timelapse/t9f1vZIJKa78)) - Oliver



I designed the top section of the shelf as a parametric model. The main dimensions were controlled using parameters so that the size of the shelf can be changed without having to remodel the entire part.



This continued the approach used in the earlier designs, making the components easier to adapt for different versions of the shelving system.



# Devlog 3 — Shelf Cover Edits ([3.1](https://lapse.hackclub.com/timelapse/aMstxW1bEyRY)) - Oliver



I modified the shelf cover so that its outside diameter matched the diameter of the vertical stand.



This made the different parts fit together more consistently and improved the overall appearance of the assembled shelving system.



# Devlog 4 — Modular Dowel Shelf Components ([4.1](https://lapse.hackclub.com/timelapse/jWxCuUXiktl2)) - Oliver



I designed several components for the modular dowel shelving system, including a microphone clip holder, a flat shelf top and the beginning of the laptop stand.



The components were designed to work with the existing dowel-based system, helping to build up the modular structure while keeping the parts compatible with each other.



# Devlog 5 — Laptop Stand and Fit Test ([5.1](https://lapse.hackclub.com/timelapse/HjkE-fCvulHD)) - Oliver



I finished the laptop stand and designed a nut and bolt holder to allow it to be mounted to the shelf.



I also created a test assembly using the components designed so far. This allowed me to check the fit and identify any issues before continuing with the full design.



# Devlog 6 — Headphone Amp Mount ([6.1](https://lapse.hackclub.com/timelapse/J3O9NKPpunH5)) - Oliver



I started by measuring the headphone amplifier and creating a test design to determine the required clearances and mounting points. I then built the main side supports and added the angled and stepped sections around the amplifier.



I added mounting holes and adjusted the sketches as the design developed.
